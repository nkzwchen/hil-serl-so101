```bash
python record_demo_so101.py --dry-run
```

该命令只检查相机及关节反馈，不执行归位或打开从臂力矩。
预检应明确实际观测键、图像形状、4 维动作空间和读取的 ROI 配置。
出现缺图、过期或同步失败时记录原因，不能把偶尔能收到图视为采集闭环通过。

## 第 2 步：从臂归位与保持验收

真机运动须在现场人员能够扶住主臂、处理回程并观察工作区域时进行。
先做一次固定起点的归位，再按结果进行重复验收；建议目标为连续 5 次通过。
更换试管或改变装配后，先核对重力补偿是否仍适用，必要时重新标定。

按现有代码/说明验收：受控关节最终误差不超过 0.4°，管子倾角不超过 3°；
按用户最新要求，主臂对齐不作为验收条件；从臂归位后的保持仍需检查，反馈必须新鲜。
记录每次归位的目标、实际位置、修正次数、最终残差、倾角和耗时。
失败时先区分补偿失配、反馈过期、主臂边界及真实不收敛，不直接调宽阈值。
不增加自动拔管，也不改变人工 RETURN 方式。

## 第 3～4 步：3 段试录与数据审计

先固定起点试录，减少随机化对首轮排查的影响：

```bash
python record_demo_so101.py --out recordings --episodes 3 --no-randomize --note pilot_fixed_start
DISPLAY=:0 python label_demos.py recordings/<会话>/ep_*.pkl
python build_demos.py recordings/<会话>/ --dry-run
python build_demos.py recordings/<会话>/
```

正常录制会进行归位和力矩控制，不能把它当成只读预检。
统计所有尝试，而不只统计最终保存的段：归位失败、图像质量失败、人工取消、合格保存分别计数。
逐段查看起始、操作中、终止附近图像与动作，核对 observation/next_observation 对应关系。
验证基座系 xyz 顺序及 2mm/步模长限制，不混入旧 3/4 维关节 demo；确认冻结关节不出现在动作向量中。
标注和转换后再确认 reward、done/mask 与成功/失败语义相符，避免只检查文件能否读出。

若图像异常导致试录频繁整段丢弃，暂停扩大采集，先提交失败分布与能否形成合格数据的结论。
相机深入排查已暂缓；此时不自行改相机驱动或降低质量门槛。完整合格段是进入下一阶段的前提。
