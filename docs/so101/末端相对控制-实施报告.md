# 末端相对控制实施报告

> 历史方案：末端相对控制已取消。当前使用 4 维相对关节角，详见《动作空间-冻结维度》。

日期：2026-10-09。此轮实现与测试均为离线执行，没有启动机器人节点或改变力矩。

## 当前控制定义

- 控制点：`gripper_frame_link` 原点，TCP 偏移为 0；不需要管尖伸出长度标定。
- 动作：基座系 dx/dy/dz，3 维连续向量，语义版本 `base_tool_origin_delta_v1`。
- 每分量输入范围 [-1,1]，缩放 0.002 米，再限制向量模长到 2mm/步；名义 10Hz。
- pan 不冻结。pan、lift、elbow、wrist_flex 四关节参与局部数值 IK；roll 保持实测值，夹爪不发送开合指令。
- 朝下姿态为偏好，最终模型倾角必须 ≤3°，不精确锁定完整旋转姿态。

## 已实现

1. IK 从当前实测关节附近求解，单步几何关节变化限制为 2°，检查 URDF 限位。
   尝试完整位移及 1/2、1/4、1/8 位移，位置误差 ≤20µm 且倾角通过才接受。
   总求解预算 40ms；耗尽或无法找到合格解时保持上一条命令。
2. 归位通过后保存本次最终补偿指令和相对实测偏差。
   零动作不再每步把实测反馈与旧补偿相加；非零动作使用本次归位获得的补偿。
3. 主臂尽力跟随从臂，保留桌面抬高偏置；2°、连续 300ms 为收敛目标，12 秒超时不阻止录制。
   主从臂反馈仍须新鲜，力矩切换失败仍停止模式转换。
4. 人工接管时记录差分基准，把主臂的目标关节变化转换为末端原点位移，经过相同 IK 与约束。
   示教动作保存实际接受的位移，缩小则记录缩小后的值，拒绝则记录零。
5. 会话和每段 pkl 均保存动作维度、语义、米制缩放及控制点。
   build_demos 拒绝缺少或不匹配这些字段的数据，包括历史三维关节动作；ROI 检查继续保留。
6. 根目录工具与 hil-serl/so101_tools 副本已同步，保留仓库副本的路径解析逻辑。
