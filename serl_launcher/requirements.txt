# 1. 删掉 tensorflow / tf-keras / tensorflow_probability(顶层)
#    代码审计结果：全代码库只有 3 处用到 TF，且都是鸡毛蒜皮：
#      · common/typing.py      仅类型标注 tf.Tensor        → 已删

#    （jax 最新版要求 >=3.12），所以钉 0.4.35 是唯一稳定选择。
#
# 3. distrax 必须钉 0.1.5（Python 3.10 约束）
#    distrax >=0.1.7 要求 Python >=3.11，py3.10 下最高只能装 0.1.5。
#    这也是 tfp 被带进来的原因。

# 4. scipy 钉 1.11.4（原版就钉了，保持）
